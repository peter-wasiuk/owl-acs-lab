# OWL Auditory-Cognitive Science Lab — Website Prototype v0.5

This is a simplified static HTML/CSS prototype for the Owl Auditory-Cognitive Science Lab at Southern Connecticut State University.

## Pages
- `index.html` — Home
- `people/index.html` — People / PI / mentorship
- `publications/index.html` — Selected Publications
- `contact/index.html` — Participant contact page with embedded SCSU Qualtrics form

## v0.5 changes
- Simplified primary navigation and removed the separate Research page; core research framing now lives on the homepage.
- Removed extra homepage labels/numbers and study-visit bullets.
- Changed “Built on Prior Work” to “Prior Work.”
- Simplified People page and added research-related photos.
- Renamed Publications to Selected Publications.
- Removed publication descriptions and Featured treatment; changed DOI buttons to “Link to Article.”
- Added the 2017 JSLHR article.

To preview, open `index.html` in a browser. The embedded Qualtrics form may behave more reliably once served over HTTPS (e.g., GitHub Pages) than when opened as a local `file://` page.

- Refined homepage affiliation and research-area wording.
- Corrected department name throughout to Department of Speech, Language, Hearing Sciences.
- Simplified the translational-goal callout by removing the label.
